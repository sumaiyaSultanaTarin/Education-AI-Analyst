# Sample / Test Data Pack

All content here is **synthetic** — fictional students, teachers, and departments —
generated by `scripts/generate_sample_data.py` for testing the intake agents
(Phase 2) before real documents are available. Regenerate anytime with:

```
python scripts/generate_sample_data.py
```

| File | Format | Exercises |
|---|---|---|
| `enrollment_results.xlsx` | Excel | Data Analyst Agent — pandas over results/enrollment rows |
| `course_syllabus.pdf` | PDF | Document Ingestion Agent — text + table extraction |
| `department_report.docx` | DOCX | Document Ingestion Agent — headings, table, bullet list |
| `scanned_result_sheet.png` | Image | Vision/OCR Agent — printed table, slight rotation + scan noise |
| `scanned_attendance_note.png` | Image | Vision/OCR Agent — short printed note, italic font, more noise |

The two `scanned_*.png` files are rendered text with simulated scan artifacts
(rotation, blur, speckle noise) rather than real scans or handwriting — enough
to exercise OCR robustness without needing actual photographed documents.
